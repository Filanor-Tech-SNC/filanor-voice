La landing **n'est pas une app séparée** — elle vit dans `apps/web/app/(public)/voix/`.

Ce dossier est un placeholder qui documente les principes éditoriaux.

## Pages prévues

- `filanor.ch/voix` — page d'entrée principale avec démos audio + pricing + CTA
- `filanor.ch/voix/salon` — variant orienté salons de coiffure (SEO)
- `filanor.ch/voix/restaurant` — variant orienté restaurants (SEO)

## Structure de page type

1. **Hero** : titre simple ("Un assistant qui répond au téléphone à votre place"), sous-titre, bouton "Écouter une démo", bouton "Prendre RDV démo"
2. **Démo audio** : player MP3 de 30-60s (vrai enregistrement de Sophie ou Marc)
3. **3 bénéfices** : zéro appel manqué / rendez-vous pris automatiquement / SMS de confirmation
4. **Comment ça marche** : 3 étapes visuelles (vous activez le renvoi / le client appelle / vous recevez un résumé)
5. **Tarifs** : 3 cartes (Starter / Pro / Setup)
6. **FAQ** : 5-6 questions/réponses
7. **Preuves / témoignages** : au départ, démos internes clairement étiquetées "exemple", puis vrais témoignages dès qu'on a des pilotes
8. **CTA final** : RDV de démo 30 min
